# Mini-OSPF Protocol Specification & RFC 2328 Compliance

## 1. Supported Packet Types

Mini-OSPF implements binary encoding, serialization, and decoding for all standard OSPFv2 packet types:

| Packet Type ID | Name | RFC 2328 Reference | Handled By |
| :--- | :--- | :--- | :--- |
| **1** | **Hello** | Section 9.5 & 10.5 | `mini_ospf.ospf.HelloHandler` |
| **2** | **Database Description (DBD)** | Section 10.6 & 10.8 | `mini_ospf.ospf.DBDHandler` |
| **3** | **Link State Request (LSR)** | Section 10.7 | `mini_ospf.ospf.LSRHandler` |
| **4** | **Link State Update (LSU)** | Section 13.0 | `mini_ospf.ospf.LSUHandler` |
| **5** | **Link State Acknowledgment (LSAck)** | Section 13.7 | `mini_ospf.ospf.LSAckHandler` |

---

## 2. Supported LSA Types

| LSA Type | Name | Purpose | Handled In LSDB |
| :--- | :--- | :--- | :--- |
| **Type 1** | **Router-LSA** | Describes router's direct interfaces, connected stub subnets, and P2P neighbor links | Yes |
| **Type 2** | **Network-LSA** | Generated by Designated Router (DR) describing broadcast transit networks | Yes |
| **Type 3** | **Summary-LSA (IP Network)** | Inter-area routes (parsed and indexed in LSDB) | Yes |
| **Type 4** | **Summary-LSA (ASBR)** | AS Boundary Router locator | Yes |
| **Type 5** | **AS-External-LSA** | External autonomous system routes | Yes |

---

## 3. Adjacency Formation Workflow

```text
    Local Router                                 Remote Neighbor
         │                                              │
         │───────────── Hello (Neighbors=[]) ──────────>│ (Remote enters INIT)
         │<──────────── Hello (Neighbors=[Local]) ──────│ (Local enters EXSTART)
         │───────────── Hello (Neighbors=[Remote]) ────>│ (Remote enters EXSTART)
         │                                              │
         │<──────────── DBD (Init=1, More=1, Master=1) ─│ (Master/Slave Election)
         │───────────── DBD (Init=0, More=1, Slave=1) ─>│ (Local enters EXCHANGE)
         │                                              │
         │<──────────── DBD (LSA Summaries) ────────────│
         │───────────── DBD (LSA Summaries Ack) ───────>│ (Exchange Complete)
         │                                              │
         │───────────── LSR (Missing LSAs) ────────────>│ (Enters LOADING)
         │<──────────── LSU (Full LSAs) ────────────────│
         │───────────── LSAck (LSA Acknowledgment) ────>│
         │                                              │
         ▼                                              ▼
    [State: FULL]                                  [State: FULL]
 (Router-LSA Updated)                           (Router-LSA Updated)
  (SPF Recalculated)                             (SPF Recalculated)
```
